Features

From pairing to privacy, every layer is designed for one job: being a second screen.

Wireless

Discover and pair on the same network

The Mac advertises itself over Bonjour as _visto._udp; open the receiver on iPhone or iPad and your host simply appears. A six-digit code confirms the first connection, then device certificates are pinned — reconnecting needs no confirmation.

  • Bonjour auto-discovery, no addresses to type
  • QUIC + TLS 1.3, ALPN visto/1
  • Six-digit first confirmation, then pinned certificates
  • Two-second control heartbeats with auto-reconnect

USB link

No Wi‑Fi? Still a second screen.

Visto reuses the system's trusted iOS device multiplexer to reach the receiver's TCP endpoint, then runs TLS 1.3 with exact certificate pinning and a dedicated ALPN on top. Measured: plaintext probes at P95 ≈ 3 ms, TLS probes 100/100 at P95 16.04 ms — video and touch flow both ways inside the same encrypted session.

  • usbmuxd trusted-device discovery, plug and play
  • TLS 1.3 + exact DER pinning + visto-usb/1
  • TLS probes 100/100, P95 16.04 ms
  • Unplug freezes the frame; reconnecting picks up seamlessly

Hardware low latency

Capture, encode, decode, render — all on hardware

The Mac captures the main display with ScreenCaptureKit at a 1/60 minimum frame interval and encodes H.264 through VideoToolbox; the receiver decodes in hardware and the Metal canvas keeps only the latest frame. The link adapts its bitrate and requests keyframes to recover from drops.

  • ScreenCaptureKit capture, NV12 straight into the encoder
  • VideoToolbox hardware H.264 encode/decode
  • Metal canvas draws the latest frame only — no queueing
  • Adaptive bitrate + keyframe recovery

Touch input

What you touch is the Mac

The receiver reports touches as normalized [0, 1] coordinates; the Mac clamps them again on decode and injects them via CoreGraphics. Taps, drags and scrolls land instantly — the extra screen doubles as a trackpad.

  • Normalized coordinates, auto-corrected on rotation or resize
  • Taps, drags and scrolls injected into the host
  • Injection only after the accessibility permission is granted
  • Text and shortcuts are separate events; logs never record content

Privacy first

Your screen stays between your devices

Both the wireless and USB links run TLS 1.3; every session enforces strictly increasing sequence numbers with replay protection; pairing pins locally generated device certificates. Mirrored video and input never transit any cloud server.

  • TLS 1.3 on both links
  • Strict inbound sequencing + replay protection
  • Local device certificates, pinned after pairing
  • No cloud relay — video never leaves the LAN
