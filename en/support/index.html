FAQ

How is Visto different from Sidecar or AirPlay mirroring?

Visto is cross-device by design: wireless runs over QUIC/TLS 1.3, and a USB cable works with Wi‑Fi completely off; touch goes straight back to the Mac as input, and a Windows host is on the roadmap. The link, protocol and stats are open for you to inspect.

What does the USB connection require?

A regular USB cable and an established trust between the iPad and Mac. USB sessions currently ship with Debug builds (shared development certificate); per-device production identity is part of the release gates.

Does video or input go to a server?

No. Both links run TLS 1.3; video and input travel only between your two devices with no cloud relay in between.

What's the latency like?

USB TLS probes measure P95 ≈ 16 ms (plaintext baseline ≈ 3 ms); encoding uses VideoToolbox hardware codecs and a Metal latest-frame canvas to trim every stage. Dynamic 1080p60 and 8-hour stability are still being validated.

When will it be released?

Visto advances through explicit gates: real USB (Gate A), the authorized macOS extension (Gate B) and Windows IddCx (Gate C) must all pass before public sale. See the Status section on the home page for current progress.
